# Quote Generator

## What is this project?

Quote Generator is a simple web application that allows users to generate a new quote by clicking a button, making it easy to discover different messages for love, courage, life, and strength.

## Who is it designed for?

This application is designed for anyone looking for a quick source of inspiration or motivation.

## The problem it solves

People often look for short messages of motivation, encouragement, or inspiration, but finding them can require searching through websites or social media.

The Quote Generator provides a simple solution by allowing users to generate and view quotes instantly in one place.

## Features

- Display and Generate quote
- Like a quote to add to favourite
- Copy quote for easy use
- Simple and easy to use

## Technologies and tools used

- HTML
- CSS
- JavaScript
- Antigravity
- Git
- GitHub

## Important decisions

I decided to keep the application simple and focused on its core functionality: generating and displaying quotes.
I chose to use HTML, CSS, and JavaScript because they were sufficient for building a lightweight and functional web application without adding unnecessary complexity.
I chose a simple interface so users can understand how to use the application without needing instructions.

## Challenges and solutions

One challenge was improving overall readability and accessibility for low-vision users

I solved this by removing all dark theme styles and theme-switching logic.
Ensuring Text-to-background contrast meets WCAG AA at minimum, AAA where possible.
Increased base font size and line-height for body text.
Added more spacing between interactive elements (buttons, links, form fields) so they're easier to target and tell apart.
Strengthened keyboard focus states with a clear, visible outline.


## How to run the project

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
